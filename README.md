# Say It for Omarchy

Private, local text-to-speech for [Omarchy](https://omarchy.org) and other
Linux desktops. Select text anywhere, press **Ctrl+Alt+S**, and a neural
voice reads it aloud, running entirely on your machine.

## Features

- **Speak from anywhere.** Ctrl+Alt+S reads the highlighted text (no copy
  needed); Ctrl+Alt+V reads the clipboard. Ctrl+Alt+P pauses, Ctrl+Alt+X stops.
- **Bar player** for the Omarchy shell: waveform with click-to-seek, play/pause,
  skip back and forward 10 seconds, speed, volume, a voice picker, and the text
  highlighted word by word as it is read. It opens by itself when you use a
  hotkey.
- **Kokoro-82M** via [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx):
  54 voices in 9 languages, about 4× faster than realtime on a laptop CPU. The
  first words play within about a second.
- **Automatic Spanish.** Text that is mostly Spanish is read with a Spanish
  voice.
- **One shared queue.** Every `sayit` call queues and returns in ~50 ms, and
  utterances play in order without talking over each other.
- **Light on memory.** The model (~530 MB) unloads after 10 idle minutes.
- **Coding-agent voice mode.** The bundled [skill](skill/SKILL.md) gives
  Claude Code (or any agent that can run shell commands) live spoken progress
  updates.
- **Local by design.** No network after the one-time model download. No
  clipboard monitoring: text is only read when you press a hotkey.

## Install

Needs systemd, PipeWire, a Wayland session, and
[uv](https://docs.astral.sh/uv/). On Arch / Omarchy:

```sh
sudo pacman -S --needed uv wl-clipboard libnotify portaudio
git clone https://github.com/txapotxapa/sayit-omarchy
cd sayit-omarchy
./install.sh
```

The installer is idempotent and needs no sudo. It creates a Python 3.12
environment, downloads and checksums the model (~350 MB), then installs:

- the `sayit` CLI in `~/.local/bin`,
- a systemd user service,
- on Omarchy, the bar player and the hotkeys (`--no-bar` and `--no-keys` skip
  them),
- the Claude Code skill, if `~/.claude` exists.

Remove it all with `./uninstall.sh` (`--purge` also deletes the model).

## Usage

```sh
sayit "Read this aloud"
printf 'Standard input works too' | sayit
sayit selection | clipboard      # what the hotkeys run
sayit pause | resume | toggle | skip | stop | clear
sayit seek -10                   # or: sayit seek --to 42
sayit voices                     # list voices
sayit voice am_michael           # default voice
sayit speed 1.25                 # applies immediately, even mid-sentence
sayit volume 0.8
sayit history | replay [N]
sayit status
sayit service start|stop|restart|status|logs
```

Options for speaking: `--voice`, `--speed`, `--lang`, `--replace` (interrupt
what is playing), and `--wait` (block until spoken).

Settings live in `~/.config/sayit/config.json`, or use
`sayit set auto_language off`, `sayit set spanish_voice ef_dora`, and
`sayit set idle_unload_minutes 30`.

### Coding-agent voice mode

Tell your agent: *"Use sayit for live spoken updates. The skill is at the path
printed by `sayit skill path`."* With Claude Code the installer already links
the skill, so "use sayit" is enough.

## How it works

```
hotkey / CLI ──unix socket──▶ sayitd ──▶ Kokoro (ONNX, CPU) ──▶ PortAudio ─▶ PipeWire
                                │
                                └─▶ $XDG_RUNTIME_DIR/sayit-state.json ──▶ bar player (Quickshell)
```

`sayitd` owns the model, the queue and the audio device. Text is cleaned
(Markdown, links and tables become speakable) and split into sentence chunks
that grow in size (~40, 100, 250 characters). Each chunk is synthesized while
the previous one plays, so playback never waits. On every state change the
daemon rewrites a small JSON snapshot. The bar widget watches that file
instead of polling, and interpolates the position while audio plays. Word
highlighting is exact at sentence boundaries and estimated within a sentence
from word length and punctuation, because Kokoro ONNX does not report word
timestamps.

## Credits

Inspired by [Say It](https://github.com/callebtc/sayit) by
[@callebtc](https://github.com/callebtc), a macOS app built on MLX. This is an
independent Linux implementation that shares its idea, its hotkeys and CLI
vocabulary, and an adapted version of its agent narration skill. Say It for

OmniVoice); this version does not have those yet.
